STUDENT COMPLAINT SYSTEM
=========================

Technology:
HTML + CSS + JavaScript + PHP + MySQL

XAMPP SETUP
-----------

1. Copy the complete "StudentComplaintSystem" folder into:
   /Applications/XAMPP/xamppfiles/htdocs/
   (Mac)

   On Windows, use:
   C:\xampp\htdocs\

2. Open XAMPP and start:
   Apache
   MySQL

3. Open phpMyAdmin:
   http://localhost/phpmyadmin/

4. Import:
   database/student_complaint.sql

5. Open:
   http://localhost/StudentComplaintSystem/
